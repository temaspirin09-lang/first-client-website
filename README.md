# Studio Marrow — premium website template

Статический сайт: `index.html` + `css/style.css` + `js/script.js`.
Без сборщиков, без зависимостей — открывается и хостится как есть.

## Локальный запуск
Открыть `index.html` в браузере, либо поднять локальный сервер (нужен для корректной работы относительных путей и загрузки шрифтов):

```
# Python
python3 -m http.server 5500

# Node
npx serve .
```

Затем открыть http://localhost:5500

## Что нужно заменить перед продажей / сдачей клиенту
- Тексты и цены в `index.html` (разделы `#work`, `#pricing`, `#contact`)
- Фотографии — сейчас подключены временные изображения с Unsplash
- Email/телефон в разделе `#contact`
- Цвета — токены в начале `css/style.css` (`:root`)
- Форма обратной связи не подключена к бэкенду — см. ниже

## Подключение формы обратной связи
Форма в `#contact` сейчас работает только визуально. Варианты подключения без бэкенда:
- **Formspree** (formspree.io) — добавить `action="https://formspree.io/f/ВАШ_ID"` и `method="POST"` в тег `<form>`
- **Netlify Forms** — добавить атрибут `data-netlify="true"` в тег `<form>` при хостинге на Netlify
- Свой бэкенд — заменить обработчик в `js/script.js`
